# Skedge 🗓️

A web-based schedule builder for Stella K. Abraham High School for Girls.

# Live Demo: 
rkamine2-sys.github.io/Skedge

# What It Does
Skedge generates conflict-free student and teacher schedules for a Jewish day school with complex constraints — tracked subjects, grade-specific course requirements, teacher availability, and 18 rooms to assign across a 9-period day.

# Features
Preloaded faculty directory with availability editor
Grade-aware student enrollment (required classes auto-populate)
Tracked subject assignment for Chumash, Navi, Ivrit, and Math
Room inventory with Science Lab and STEM room priority logic

# Tech
HTML · CSS · Vanilla JavaScript

# Status
Data entry layer complete. Constraint satisfaction scheduling algorithm in development.
